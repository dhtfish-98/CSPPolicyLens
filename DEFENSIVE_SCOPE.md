# Bounded defensive contract

The selected upstream is google/csp-evaluator at ad530f3ae5473f9e03c8bf500ee0ada8d9e9b822. All selected core parser/model/evaluator/checker files, their tests and license/metadata were read completely. The rewritten scope is CSP tokenization, first-wins duplicate handling, positioned normalized directives, CSP2/3 effective fallbacks, nonce/hash grammar, strict-dynamic and unsafe-inline effects, object/base restrictions, Trusted Types and multiple-policy reports. The full upstream frontend, browser integration, URL matcher, address database and bypass checks are excluded.

Models use [CSP2 Recommendation](https://www.w3.org/TR/CSP2/), selected algorithms from the [2026-09-16 CSP3 Working Draft](https://www.w3.org/TR/2026/WD-CSP3-20260916/) and selected configuration semantics from the [2026-06-23 Trusted Types Working Draft](https://www.w3.org/TR/2026/WD-trusted-types-20260623/). Draft models are not a claim that every browser implements these behaviors.

Fetch directives use the applicable ordered fallback list. Base-uri, form-action and frame-ancestors never inherit default-src. CSP3 worker-src falls back through child-src, script-src, default-src; CSP2 uses child-src/default-src for workers. CSP3 elem/attr directives can override script/style-src. String and Wasm evaluation use script-src/default-src, regardless of elem/attr directives.

Nonce/hash tokens preserve case-sensitive payload identity and the applicable version's grammar. A grammar-matching token can suppress unrestricted unsafe-inline without proving that it matches any real element. No element contents, nonce randomness or hash digest correctness are evaluated. Nonce length is a textual heuristic warning, not entropy evidence. CSP3 strict-dynamic suppresses unrestricted script inline behavior and ignores URL sources for script loading; it does not suppress style unsafe-inline. Non-parser-inserted loading and runtime script chains are not evaluated. Experimental/unsupported keywords remain OPEN.

An empty source directive restricts its target even when default-src is permissive. Mixed 'none' does not override other sources. Arbitrary URLs, origins, redirects, plugin behavior and allowlist intersections are not matched. Object loading is proven blocked only when at least one enforced effective source list permits no selected URL source; otherwise restricted allowlists remain OPEN. Base URLs outside self are proven blocked when one enforced base-uri permits no URL or only self. Known absence/network-wildcard cases are finite baseline failures, not exploitation claims.

Trusted Types sink requirements and allowed creation names are separate. Enforced name sets intersect, wildcard is the universe, duplicate-name allowances require every enforced policy to allow duplication, and report-only directives are excluded. Names remain case-sensitive and digest-only. Configuration cannot prove policy callback correctness or sanitization, and default policy code is not examined. Noncanonical or unsupported tokens remain OPEN.

The immutable local envelope is caller evidence, not an HTTP response capture or provenance attestation. Metadata/delivery mode is explicit; HTML meta timing and unsupported sandbox effects remain OPEN. All limits are finite, overloads never produce clean PASS, and report compaction retains known violations. No attack payload, target reconnaissance, host database, remote request, deployment, execution or XSS-elimination capability is supplied.

Effective directive rows describe raw URL source classes, with separate script-specific ignored-token effects; no field claims actual external-script URL matching. Trusted Types duplicate-name fields describe only the CSP configuration. The separate createPolicy API uniqueness rule for the default name, and actual callback/API behavior, remain OPEN.
